# График сотрудников

Локальное веб-приложение для визуального составления и редактирования графиков работы сотрудников на месяц.

## Возможности

### Основной функционал
- **Таблица графика**: строки — дни выбранного месяца, столбцы — сотрудники.
- **Выделение выходных**: суббота и воскресенье отображаются светло-серым фоном.
- **Навигация по месяцам**: кнопки «Пред. / След.» и выбор месяца через календарь.
- **Редактирование ячеек**: клик по ячейке открывает боковую панель с выбором обозначения смены.
- **Управление сотрудниками**: добавление, удаление, переименование столбцов.
- **Обозначения смен**: настраиваемый набор кодов (например, Д — дневная, Н — ночная, В — выходной) с цветом и названием.
- **Шаблоны повторения**: создание паттернов смен (например, Д-Д-Н-Н-В-В) и применение их к сотруднику.
- **Несколько графиков**: создание нескольких вкладок-графиков, перенос данных между ними.
- **Вертикальные имена**: возможность отображать имена сотрудников вертикально в заголовках столбцов.

### Drag & Drop столбцов
Заголовки столбцов сотрудников можно перетаскивать мышью для изменения порядка.

- **Переключатель «Закрепить столбец»** (включён по умолчанию): при перемещении сотрудника вместе с ним перемещается и его столбец смен. При выключении перемещается только имя, а данные остаются на прежних позициях столбцов.
- **Переключатель «Обмен местами»**: включён — перетаскивание одного сотрудника на другого меняет их местами; выключен — сотрудник вклинивается между другими со сдвигом.

### Sticky-заголовки при скролле
При вертикальной прокрутке страницы:
- Переключатели режимов перетаскивания остаются видимыми у верхнего края экрана.
- Строка с именами сотрудников прилипает под переключателями.
- Ячейки сотрудников уменьшаются по высоте и показывают первые 4 символа имени вертикально.
- Шрифт в свёрнутых ячейках не изменяется, ширина столбца остаётся прежней.
- Столбец «День» также закреплён и уменьшен.

### Сохранение и экспорт
- **Автосохранение** текущего состояния в `localStorage` браузера.
- **Экспорт / импорт** всей базы графиков в JSON.
- **Экспорт** текущего графика в Excel.
- **Экспорт** всей таблицы или выделенной области в JPG.
- **Печать** оптимизированного вида таблицы.

## Запуск

```bash
npm install
npm run dev
```

Приложение откроется в браузере по адресу `http://localhost:5173`.

## Сборка

```bash
npm run build
```

Результат сборки помещается в папку `dist`.
