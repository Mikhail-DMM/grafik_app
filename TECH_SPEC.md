# Техническое задание: График сотрудников

## Назначение
Локальное веб-приложение для визуального составления и редактирования графиков работы сотрудников на месяц.

## Основной функционал

### 1. Таблица графика
- **Строки** — дни выбранного месяца (1–31)
- **Столбцы** — сотрудники (динамический список)
- Суббота и воскресенье выделяются светло-серым фоном
- Навигация по месяцам (предыдущий / следующий)
- Выбор месяца через календарь или выпадающий список

### 2. Ячейки таблицы
- Заполняются буквенные обозначения или иконки (например: Д — дневная, Н — ночная, В — выходной, О — отпуск, Б — больничный)
- Клик по ячейке открывает выбор значения из настроек
- На вкладке «Настройки» пользователь определяет собственный набор обозначений (название + цвет / иконка)

### 3. Управление сотрудниками
- Добавление / удаление сотрудников (столбцов)
- Переименование сотрудника
- Порядок столбцов — фиксированный ( Drag & Drop для перемещения — опционально)

### 4. Шаблоны повторения (паттерны)
- Пользователь создаёт шаблон последовательности смен (например: Д-Д-Н-Н-В-В)
- Применение шаблона к конкретному сотруднику на выбранный период
- Сохранение шаблонов в списке для повторного использования

### 5. Сохранение и экспорт
| Способ | Описание |
|--------|----------|
| **localStorage** | Автосохранение текущего состояния в браузере |
| **JSON-файл** | Скачивание / загрузка графика целиком |
| **Excel-файл (.xlsx)** | Скачивание готового графика для печати / отправки |
| **Печать** | Оптимизированный вид для печати через `window.print()` |

### 6. Статистика
- Количество отработанных смен по каждому сотруднику за месяц
- Расчёт по типам смен (дневных, ночных и т. д.)

## Структура приложения

```
График сотрудников
├── Вкладка «График» — основная таблица
├── Вкладка «Настройки» — обозначения смен, шаблоны
└── Вкладка «Статистика» — сводка по сотрудникам
```

## Стек технологий

| Компонент | Технология |
|-----------|------------|
| Framework | React 18+ |
| Язык | TypeScript |
| Сборка | Vite |
| Стили | Tailwind CSS |
| Excel-экспорт | xlsx (SheetJS) |
| Хранение | localStorage + File API |

## Требования к интерфейсу
- Адаптивная таблица (горизонтальная прокрутка при большом количестве сотрудников)
- Выходные строки визуально отличаются (серый фон)
- Выбранный месяц и год — в шапке
- Кнопки: «Добавить сотрудника», «Удалить сотрудника», «Скачать JSON», «Скачать Excel», «Печать»
